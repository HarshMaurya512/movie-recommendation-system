# 🎬 Movie Recommendation System

A movie recommendation system built using Python, Pandas, NumPy, Scikit-learn and Streamlit.

## Features

- Movie data preprocessing
- Content-based movie recommendation
- Cosine similarity
- User viewing history
- Personalized recommendations based on previously watched movies
- Streamlit web application

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Joblib
- Streamlit
- Jupyter Notebook
